# 45 12 08 — Binary Eye

A small HTML/CSS/JS visual prototype designed around an iPhone 12 Pro Max CSS viewport (428 × 926).

## Current composition

- `45 12 08` at the top
- A binary-character eye in the center
- Slow 3D-style rotation
- Periodic blink
- Korean text: `무엇을 원하십니까?` ("What do you desire?")
- No countdown/timer logic in this repository

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Files

- `index.html` — structure
- `style.css` — layout, typography, rotation and blink animation
- `script.js` — procedural binary eye
